# Практическая работа №2. Вариант 14

Программа для анализа зависимостей пакетов npm.
Язык реализации — Python.

## Этап 1

Реализованы ввод настроек через командную строку, проверка
параметров и вывод их значений. Получение зависимостей
и создание изображения будут добавлены на следующих этапах.

## Параметры

- `--package` — имя пакета.
- `--repository` — URL репозитория или путь к тестовому файлу.
- `--test` — включить работу с тестовым файлом.
  Без этого флага используется обычный режим.
- `--version` — версия пакета, например 4.18.2.
- `--output` — имя выходного файла с расширением .png.
  Папка для сохранения должна существовать.
- `--max-depth` — максимальная глубина анализа:
  целое неотрицательное число.
- `--help` — справка по параметрам.

Все параметры, кроме `--test` и `--help`, обязательны.
На первом этапе изображение ещё не создаётся.

## Функции

- `package_name` — проверяет имя пакета.
- `package_version` — проверяет формат версии.
- `depth_value` — проверяет глубину анализа.
- `output_file` — проверяет расширение и путь выходного файла.
- `check_repository` — проверяет URL или наличие тестового файла.
- `get_settings` — получает и проверяет параметры командной строки.
- `main` — выводит настройки в формате ключ-значение.

## Запуск

Требуется Python 3. Отдельная сборка и установка сторонних
библиотек для первого этапа не нужны.
Команды выполняются из корня проекта.

```powershell
python src/main.py --package express --repository https://registry.npmjs.org --version 4.18.2 --output graph.png --max-depth 3
```

Запуск через скрипт Windows:

```powershell
.\run.bat --package express --repository https://registry.npmjs.org --version 4.18.2 --output graph.png --max-depth 3
```

## Тестирование

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют корректные настройки, тестовый режим,
неверные значения параметров и отсутствие тестового файла.

Пример проверки ошибки: отрицательная глубина анализа.

```powershell
python src/main.py --package express --repository https://registry.npmjs.org --version 4.18.2 --output graph.png --max-depth -1
```

Ожидаемое сообщение: «Глубина не может быть отрицательной».
